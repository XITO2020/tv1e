## INSTALLATION HERMES (souverain)

3 OS supportés, une journée sur place ou à distance :
- **Linux** (Ubuntu/Debian/Arch) : installeur de l'agent (OpenClaw/Hermes) en bash + Ollama + systemd
- **macOS** (Apple Silicon ou Intel) : installeur natif + Ollama + LaunchAgent
- **Windows** : installeur natif PowerShell, plus besoin de WSL2
- Contexte 64 000 tokens obligatoire pour l'usage avec outils (OLLAMA_CONTEXT_LENGTH=64000)

Modèles déployables selon hardware :
- 8 GB RAM CPU only → Phi-3 Mini 3.8B (POC, démo)
- 16 GB + GPU 8 GB VRAM → Qwen 2.5 7B (mairie, cabinet)
- 32 GB + RTX 3080/4080 → Llama 3 8B / Mixtral 8x7B (PME prod)
- 64 GB + RTX 4090 → Qwen 32B / Llama 70B Q4 (multi-utilisateurs)
